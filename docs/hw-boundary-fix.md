# HW-123 方向判定修正（2026-09-11）

## 根據保存影像確認的問題

`S02-HW-dark-after-fix-diagnostic-01/scene-after-sample.jpg` 原始模型 confidence 0.616，模型框約 122×153px，但角點只圈中間約 30×20px 的晶片区域；既有 PCB 細化不接受這麼大的面積變化，錯誤四角直接進方向驗證。

第二張 `S02-HW-boundary-fix-live-01/scene-after-sample.jpg` 為角點歪斜，並非缩小。這兩張都屬取樣後另拍，不是所有失敗影格的完整證據。

## 已實作

- 僅 HW、僅目前原始模型框內尋找藍色 PCB，要求單一候選、面積／比例／填充率符合限制。
- 角點縮小可以重建；非縮小時，候選須在兩軸覆蓋模型框至少 85%，避免被遮住後縮到其他元件列。
- 邊界候選必須再次通過既有四方向、全列規律焊盤與兩側間隙對比，原 18/22 對比及 15 分方向差門檻未放寬。
- 沒有候選不捏造位置；方向失敗即撤銷舊 Pin，區分目前找到候選與有效 Pin 次序。新增中英文「已找到零件，腳位方向待確認」提示，不新增確認按鈕或操作門檻。
- 第一版的遮擋回歸曾誤抓另一列，已以完整邊界限制修正，原遮擋測試恢復通過。
