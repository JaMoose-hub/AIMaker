# VLM 視覺接地實戰手冊（P0/P1 的證據基礎與實作規則）

延續 [software-architecture-plan.md](software-architecture-plan.md) §6（Tier 1 VLM 層）與
[cloud-plan-and-edge-vlm-architecture.md](cloud-plan-and-edge-vlm-architecture.md) §4（VLMWorker）。
本文件回答「如何讓地端 VLM（Qwen3-VL 4B/8B via Ollama）看得懂板子與接線且辨識準確」，
每條規則附文獻依據。調研日期：2026-07-29。

## 核心結論

**雙通道注入是全部文獻中效果最大的單一手段**：
結構化文字狀態（Tier 0 JSON）+ 燒錄語意標籤的影像，兩者一起送。
量化依據（病理學標籤注入研究，N=3,888）：影像上有正確文字標籤時模型準確率
**90–100%**，無標籤基線僅 **30–65%**（medRxiv 2024.12.11.24318840 / NEJM AI）。
CCoT（CVPR 2024）證明結構化文字事實對 13B 級開源模型同樣有效、零微調。

## 規則（依證據強度排序）

### R1 — 文字通道：Tier 0 狀態為權威來源
Prompt 附上 JSON：腳位表、每條線的兩端腳位、顏色、信心值、guidance 判定。
並明示「此偵測狀態為權威來源，以其為準」。
VLM 在圖文衝突時**不成比例偏好文字**（typographic 研究）——對我們是利多，
因為文字是幾何管線的權威輸出。

### R2 — 影像通道：燒錄「語意標籤」，不是 SoM 編號標記
**關鍵修正**：經典 Set-of-Mark（抽象編號①②③→模型回報對應）在 4–8B 模型上
**不可靠甚至有害**——SoM-LLaVA（arXiv 2404.16375）實測 LLaVA 7B/13B 無法遵循
SoM 標記，通常反而降低表現（開源預訓練資料中帶標記影像僅 ~0.002%）。
改為直接燒錄**語意文字標籤**（"D7"、"GND"、"A0"）在投影位置上——這只需要
OCR 能力，而 OCR 正是 Qwen3-VL 同級最強的能力（OCRBench/CC-OCR）。

### R3 — 標註樣式規格
- 高對比純色：**紅/品紅**為主（CLIP 紅圈研究：紅圈 33.5% > 箭頭 28.3% > 框 24.1%；紅色為最佳色 36.4%——遷移到 chat VLM 屬合理外推）
- 規則形狀：圓圈圈住線材端點、圓角底色框裝腳位名
- 線寬 1–3px、標籤文字 ≥12–16px（以**模型實際輸入解析度**計，估計值）
- Leader line 偏移排版避碰，**絕不遮住針腳或線材端點本身**（SoM 論文的標記配置原則）
- **Arduino 特別警告**：板上絲印本來就印滿腳位編號——我們的標籤必須用明顯
  不同的視覺語言（有底色的圓角標籤框＋高對比字），讓模型能區分「系統標註」
  與「板上絲印」（arXiv 2404.16375 的多數字場景警告）

### R4 — 每張圖 ≤10–15 個標記，動態篩選
高密度標記稀釋注意力（GUI grounding 文獻），臨界值無精確數字（估計 ≤10–15）。
只標：有接線的腳位＋當前 guidance 目標腳位＋被問到的腳位。不要全板 32 支全標。

### R5 — 信心值閘門（安全關鍵）
**錯誤的燒錄標籤會把準確率打到 0–10%，且模型不會質疑、prompt 無法緩解**
（同一病理學研究：模型把影像內標籤當不可質疑的真相，連明顯錯誤也照抄）。
因此：低信心偵測**不燒錄**（或用「?」樣式並在文字狀態標 uncertain）。
寧可少標，不可錯標——與本專案 never-guess 紀律完全同構。

### R6 — 前處理：ROI 裁切 + 全圖並送
MLLM 準確率對視覺主體大小極度敏感（ICLR 2025，因果確認）；但裁切傷害全局
問題（計數、相對位置）。做法（CropVLM 模式）：送「板面 ROI 裁切（放大）」+
「縮小全圖」兩張。計數類問題（「共幾條線？」）靠文字狀態回答，不靠圖。
標籤在 resize 之後的最終解析度上繪製。

### R7 — Prompt 防護
明示「彩色標註為系統疊加的輔助資訊，不是實體物件；敘述場景時使用標註資訊
但不要描述標註圖形本身」。對「偵測對不對？」這類驗證性問題，另備無標註
原圖通道，避免循環自證。

### R8 — 上線前 A/B 冒煙測試（M28 驗收項）
同一批真實 keyframe 以四種條件各問 10 題：(a) 裸圖 (b) 僅燒錄標籤
(c) 僅文字狀態 (d) 雙通道。量測腳位命名準確率。文獻支持 (d) 最佳，但
4B 級距沒有直接發表過的數字——照本專案慣例，實測後才宣稱。
Ground truth 由幾何管線自動生成（本專案第一次有自動標註員）。

## 已知失效模式（誠實記錄）

| 失效 | 依據 | 對策 |
|---|---|---|
| 錯誤標籤被照單全收（0–10% 準確率） | medRxiv/NEJM AI 研究 | R5 信心閘門 |
| 模型把標註當實體敘述（「板上有個紅圈」） | 可預期（估計） | R7 prompt 防護 |
| 諂媚：使用者否定時放棄正確答案 | MM-SY benchmark | 判定類問題一律引用文字狀態作答 |
| 板上絲印數字與標籤混淆 | arXiv 2404.16375 | R3 視覺語言區隔 |
| 標記過多注意力稀釋 | GUI grounding 文獻 | R4 動態篩選 |
