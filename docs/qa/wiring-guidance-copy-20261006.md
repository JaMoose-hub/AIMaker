# 簡化接線疑點說明 — 2026-10-06

## 使用方式

主回覆先指出零件上的標字與實際觀察到的線色，簡短說明疑點，再提供一個核對
動作。只有照片有具體錯接線索才說「疑似接錯」；看不到插接處不等於鬆脫，
也不直接代表接錯。單次線色差異仍是待核對的線索，診斷與人工確認紀錄不升級。

實體 Pin／GPIO 編號移到詳情。使用者可展開「查看應接位置」，以內／外排及
遠離 USB／網路孔的一端找到設計位置。圖面是設計接法，不是模型已確認的照片
位置。沿用既有 Pi 5 Profile 與排針位置 helper，保存的 pin ID 與 index 不符時
不畫位置。圖內選線只改閱讀焦點。

桌面與手機共用摘要元件。顯示層沿用目前訊息凍結的證據與當前線路，不使用
已處理的其他疑點取代現在的步驟。具體裸露／未套接觀察仍保留。
