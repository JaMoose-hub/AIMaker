## 重啟時發現的原圖保存問題

舊 DebugSessions 只將原圖 bytes 存在記憶體，磁碟只有照片 metadata。第一次重啟後，現有三張照片的歷史 URL 回 capture_not_found。搜尋原檔及瀏覽器資源取回均未恢復原始 bytes；沒有使用相似影像或裁切圖替代原照片。

補上原圖／衍生裁切的原子保存及 SHA 驗證。新拍攝照片可在重啟或記憶體過期後只讀查看；重啟仍使 available=false、current=false、照片輪次 stale，context 不恢復，沒有恢復分析、人工確認或硬體操作權限。缺檔、毀損、越界與未知視角均拒絕供圖。

此次舊三張照片未落盤，無法恢復，需要重新拍攝。正式頁面已恢復到新的 Pi 第一側問題，示意圖直接顯示，沒有替使用者拍攝、確認、分析或重測。
