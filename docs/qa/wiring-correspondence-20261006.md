# 三張接頭照片：接反疑點與補拍流程修正

## 本輪目標

使用者確認 Demo 能提出合理疑點即可；不要求照片完成電氣或全線路驗證。
原案例零件標字清楚，但 Pi 排／柱判讀不完整，且程式把「疑似接錯」與
完整導線證據綁在一起，導致反覆要求補拍。

## 實作

- `wiring_photo_pipeline.py`：`poc-exit-pin-demo-2048-v8-candidate-seat`。
  記錄 Pi 內外排、從 Pin 1／2 端起算的位置、可見插頭底部、方向與計數依據。
  後端從 profile 換算候選腳號，附上原照 capture ID、hash 與尺寸。
  有遮擋時可依可見針距和空位提出估計，需記錄依據；無法取捨的多個候選保持未知。
- 排針外殼位置可作為照片候選，即使插入深度不確定；不要求看到外殼內部金屬。
  拍攝目標、出線口順序、線色和預期接法都不提供實體脚號。
- `guided_wiring_review.py`：新增兩條線的互換疑點，使用獨立腳位觀察、零件
  自身標字及唯一線色的交叉關係。沒有完整線路也能輸出 `suspected`。
  `same_wire` 仍為 `uncertain`，不產生自動接線確認或功能通過。
- 同一腳位的相符視角合併；同視角多個同色接頭、相矛盾位置、模糊標字或
  中間連線不強行組成互換。另一張遮擋不抹除清楚的觀察。
- 補拍保留其他來源仍有效的觀察，重新比較整組端點。舊路徑只有兩端來源及
  分析版本仍吻合時保留；來源變更，即使重用候選 ID 也會失效。
- 前端維持簡短主摘要與下一步，既有詳情顯示候選位置、設計腳位及照片依據。
  候選互換不使用已確認路徑欄位，避免空值或誤導高亮。
- 沒有新增拍照步驟、硬體操作或模型階段；維持兩次雲端呼叫。

- 既有零件標字、摘要、雙階段、補拍及 schema 回歸：13 項。
- 前端疑點與詳情渲染：6 項。
- 調整候選指令後重跑兩項相關後端檢查：2 次。
- `npm run build` 成功；保留既有大型 chunk 提示。
- `git diff --check` 成功；既有換行格式提示不影響檢查。

這些軟體檢查與照片判讀結果分開計算，不代表實機或電氣驗收。

## 真實照片重測

沿用 `runs/component-identity-20261006` 的同三張原照與保存設計，未補拍、未改圖。
獨立 replay 不寫入現場工作階段或人工确认，不操作 Pi。每次明確執行最多
2 次 GPT-6.1-Sol／low 呼叫，透過正式 pipeline 產生結果；提示不包含人工
判讀的交換答案。完整提示、schema、回覆、圖片來源 hash 與耗時保存在
`runs/wiring-correspondence-20261006/attempt-1/`。

第一輪 v7：兩次真實模型呼叫，出線／線色 48.343 秒、腳位 78.250 秒，
程式端總耗時 127.250 秒。零件標字保存正確，但 Pi 除起端紅線外仍多數
未提供候選位置，未提出接反疑點；照片驗收未通過。這個失敗結果保留不覆寫。

第二輪 v8 重用第一輪出線盤點，只再做腳位判讀。重用前核對三張照片的
capture、原圖 hash／尺寸、裁切與分析圖 hash 一致；正式產品的版本快取
規則不因這次隔離實驗而放寬。腳位指令改為有照片依據的候選判斷，允許
利用可見針距與空位推定位置，仍不得用線色或預期接法反推腳號。

第二輪結果保存於 `attempt-2/`，1 次真實 GPT-6.1-Sol／low 呼叫，模型耗時
114.453 秒、程式端總耗時 115.031 秒，沒有新增照片。

| 端點 | 原照的模型候選 | 零件自身標字 |
| --- | --- | --- |
| 黃線 | Pi 外排第 6 位，Pin 12／GPIO18 | TRIG |
| 紫線 | Pi 內排第 6 位，Pin 11／GPIO17 | ECHO |
| 紅線旁的藍線 | Pi 外排第 3 位，Pin 6／GND | GND（照片中另有同色線，未證明同線） |

正式比較器輸出：

> TRIG 與 ECHO 疑似接反。
>
> 核對 TRIG → Pi Pin 11、ECHO → Pi Pin 12；要調整接線請先斷電。

兩個訊號結果為 `suspected / reciprocal_endpoint_swap`，`same_wire=uncertain`；
沒有完整線路、人工確認或功能通過。GND／VCC 保持不確定，沒有把相符線色
升級為通過。回覆不再要求重拍零件或 Pi。

本輪共兩次照片實驗、三次真實模型呼叫；加上 42 次軟體測試，仍在使用者
50 次上限內。這是一組開發用照片的回歸成功，不是獨立準確率驗收。
第一輪失敗與第二輪結果均保留；未把人工推定答案送入模型提示。
115 秒是重用出線盤點後的單次腳位重判，尚未證明完整流程更快。
