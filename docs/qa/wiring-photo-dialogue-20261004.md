# 接線照片對話引導（2026-10-04）

## 操作與證據界線

- 沿用除錯／接線核對工作階段。拍照時只呈現目前的一個問題：Pi 第一側、Pi 另一側、相關零件接頭。
- 照片顯示為使用者回覆，再詢問「使用這張」或「看不清楚，重拍」。已選照片與取景示意放在可展開項目，操作按鈕至少 44 px。
- 固定拍攝提示由本地狀態產生，不為每張引導呼叫模型。三張人工選用後，仍要明確按下分析。
- 新版伺服器保存 `photo_acceptance`，綁定角色、照片 ID、雜湊與輪次；桌面與配對手機共用。它只表示照片選用，不會寫入接線人工確認或啟動硬體。
- 重拍只撤銷該視角的選用；改線／過期則失效本輪。框選保留照片選用，但不確認腳號。
- 手機在原本對話內使用相機檔案上傳，沿用附件服務及受配對憑證保護的 API。照片收集不要求完整 Pi pose 或即時串流影格；實際換鏡頭、換作品或遲到操作仍受版本檢查。
- 手機可查看分析依據；實際接線確認與重測仍由既有桌面流程明確操作。
