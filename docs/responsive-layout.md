# 五階段 RWD 驗收紀錄

更新：2026-09-21

## 範圍

01 設計作品、02 Blueprint、03 Pin 接線引導、04 測試與除錯、05 部署與執行，以及共用模型／Pi 工具列。

使用 `frontend/src/responsive.css` 統一斷點，於既有樣式之後載入。只調整排版，不依寬度重新掛載頁面，不修改辨識模型、相機座標換算、接線紀錄、草稿、測試判定或 Pi 執行管理。

## 行為

- 寬桌機保留左右分欄；區塊依工具列實際高度填滿剩餘空間，不再假設固定 165px 頁首。
- 960px 以下改為單欄；手機／平板與 600px 以下的短視窗使用頁面捲動，避免內容被固定高度截斷。
- 1500px 以下導覽獨立一列；600px 以下五階段以三欄換行，不需要橫滑找頁面。
- 小螢幕主要操作至少 44px 高。模型、Pi 執行管理、圖面彈窗限制在可用寬度內。
- 接線引導的顯示／隱藏按鈕移出影像矩形；手機鏡像、即時追蹤和校正方向控制不互相遮擋。原影像與藍框座標樹不改動。
- 接線圖、程式碼、腳位列允許區塊內捲動；不是讓整頁橫向溢出。即時數值維持固定欄寬並依容器寬度換行，不使用捲軸、不隱藏資訊；數字更新不改變欄寬。
- 除錯狀態卡依寬度排列；長文字可換行，日誌區獨立捲動。部署程式編輯器保留原碼行與 Tab 操作。
- 保留智慧眼鏡／HUD 獨立顯示模式，不用 RWD 規則更改其座標或辨識。
