## 04 測試與除錯

- 「幫我檢查」沿用唯讀診斷，不自動停止作品、測試硬體或呼叫 AI。

- Pi／兩個零件／作品狀態維持四張固定卡；歷史測試、失效結果不冒充本次通過。

- AI 區塊預設收起，只有按分析才送出；試跑的停止與實體目視確認保持可見。

## 05 部署與執行

- 程式編輯、環境準備、完整輸出與版本預設收起。原生 details 不卸載編輯器，收合不清除草稿。
- 保留斷電接線、3.3V／BLK 注意事項，以及「程式執行不等於硬體測試通過」。
- 遇到問題可以帶著原有執行版本與日誌返回 04。
