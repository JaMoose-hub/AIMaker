## 舊作品轉換

頁面掛載與自動儲存之前，若作品或已選零件包含退役項目：

1. 先把原始 JSON 備份到瀏覽器 localStorage 的 `boardvision.maker.v1.before-hw123-removal`，不覆寫既有備份。
2. 呼叫本機 `POST /api/design/migrate-retired`，不呼叫雲端、不部署。
3. 保留作品 ID、其餘零件順序、參數與可用邏輯；依現行共用目錄重新產生接線、材料、依賴與程式碼，版次加一。
4. 保留 HC/TFT 簽章一致的人工接線紀錄；刪除 HW 紀錄，依零件 ID 重新對應目前步驟。
5. 含舊零件的組裝圖不再沿用，需使用者另行產圖。手動程式碼保存在原始備份，現行編輯器改用新零件配置產生的程式碼。
6. 僅有 HW 的作品變成空白設計，不能假裝已完成另一件作品。歷史對話保留為紀錄。

寫入備份、服務或轉換驗證失敗時，不掛載自動儲存介面、不覆寫原始草稿；畫面提供重試。
